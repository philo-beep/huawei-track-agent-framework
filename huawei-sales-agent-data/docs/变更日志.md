# 变更日志

## 2026-10-22

### 销售文案去技术化

- 将页面、交互提示、错误提示、结果展示和销售说明中的开发术语改为销售顾问可理解的业务表达，例如智能分析、产品资料库、公开资料查询、发布前检查、销售配置和下载数据备份。
- 生成结果不再直接展示模型名、内部编号、排序分、原始数据或开发字段；完整数据仍保留在数据备份中，供技术、审计和系统存档使用。
- 错误提示不再暴露结构路径、字段名、数组、字节长度、令牌、会话、哈希或接口实现信息。
- 重新生成 `content_draft.example.json`、`content_draft.example.md` 和 `content_draft.safe.example.md`，使样例与当前销售可读的输出一致。
- 新增销售文案回归测试，覆盖导出 Markdown 和销售可见错误提示，阻止技术词重新进入销售主视图。
- 验证：Node 核心 27/27、扩展回归 15/15、本机 HTTP 13/13、Python 7/7；静态页面和销售文档扫描无目标技术词。`verify_product_data.js` 仍因主工作区缺少既有 `product_registry.json` 无法执行，不记为通过。
- 本轮仅修改展示层和文案，不改变选品、画像、报价计算、发布检查或接口契约。

### 客户画像销售本位问法与外部方案调研

- 明确画像工具使用者为华为销售顾问；访谈输入是销售顾问录入的客户原话、转述或观察，不把销售顾问本人当作客户。
- 画像维度与默认问题改为客户本位称呼，并修正“客户回答”“对话习惯”“了解平台”等不适配表述。
- 逐题画像提示词增加销售顾问视角约束：问题主语必须是“客户/这位客户”，禁止询问销售顾问自身岗位或经历。
- 程序增加自指问题防护，模型若生成“您在公司的岗位是什么”类问题时降级为客户本位问题；8 轮上限、覆盖阈值和停止机制不变。
- 完成 GitHub 公开方案调研，对比 AI Sales Team Claude、SalesGPT、TinyTroupe、Buyer Criteria Skill；详细记录见 `画像调研对比-20261022.md`。
- 本轮仅落地销售本位措辞修正，不引入第三方代码；BANT/MEDDIC 扩展、证据来源类型和销售阶段等优化等待审验确认。
- 验证：逐题画像测试 7/7 通过；真实 DeepSeek 冒烟返回“您记录的这位客户在采购中担任什么角色”，问题对象正确指向客户。
