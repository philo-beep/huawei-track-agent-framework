- 新增离线与本地 HTTP 测试，覆盖图文契约、事实回溯、错误型号拒绝、图片来源、图片哈希、任务轮询和导出。结果只证明工程链路可用，不证明发布授权、真实咨询或转化。

- IMA 通过 `https://ima.qq.com/openapi/wiki/v1/*` 接入；已验证知识库搜索与知识检索，并识别默认知识库“任德耀新建华为PC知识库”。

- 页面与 API 增加三项按请求开关：云端模型、IMA、联网检索；未勾选或未配置时不会静默调用。
