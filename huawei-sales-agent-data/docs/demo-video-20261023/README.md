任务日期：2026-10-23。归属：E 产品与答辩工作区。

用户确认的主线为**个人单人购买一台笔记本**，并要求软文内实际展示配图。使用产品已有的“自由职业创作者”样例，不采用企业采购或五台价格演算。

## 展示内容与真实性

1. 从产品真实预登录页开始，点击进入、逐字输入演示账号和掩码密码，完成实际登录。
2. 逐字输入个人客户的已知背景，再点击产品自带的个人预置样例。录制脚本逐步点击“填入本轮回答”和“确认本轮并保存”，六轮回答保留在各自问题下供阅读。
3. 依次呈现角色、使用地点、需求与偏好、单台数量和未知预算、沟通偏好、软件版本与文件格式顾虑，并展示画像的原话证据。
4. 将画像带入选品，查看候选、推荐理由、待确认条件和产品资料出处。
5. 展示三平台软文：小红书三张、公众号四张、朋友圈一张正文插图，共八次完整配图展示。插图为现有项目原创场景 SVG，明确标为非产品实拍，不当成外观、兼容性或效果证据。
6. 查看原稿六项审稿记录、安全版本、全文和复制功能。快照审稿记录不冒充当次在线审核。
7. 个人样例正式价格保留待确认。镜头展示华为公开产品资料卡的正式成交价状态，再呈现任务验证计划、销售负责人和后续动作。
8. 实际下载销售说明，完成本次演示闭环。

所有业务操作都在产品现有界面内进行。未拦截或伪造 API 响应，未往页面注入结果或修改业务状态；添加到浏览器的脚本只绘制可见鼠标与点击圆环。页面录制后缩放、增加上下信息栏，配音与字幕按真实时间轴合成。

六轮及后续内容读取产品已保存的本地预置，不声称重新调用了模型、知识库或在线生成服务。预置客户是合成个人样例，产品信息沿用保存的公开资料快照。未实际联系客户、发布、下单或成交。正式价格和兼容性仍以实际核验为准。

## 配音与字幕

声音使用 `zh-CN-XiaoxiaoNeural` 中文神经语音，语速 `+3%`、音高 `-1Hz`，通过日常口语、提问和标点形成自然停顿。属于语音合成，非真人录音。无背景音乐，保留人声清晰度。使用语音服务返回的逐词时间边界生成字幕，按句意分行；成片统一响度到约 -16 LUFS。

## 复录方式

环境：Node.js、Playwright 1.62.1、Chromium；Python 3.14、`requirements.txt` 中的依赖。运行时会访问语音合成服务，只发送本目录固定讲解稿，不发送客户输入。

```powershell
# 在本目录安装录制依赖；项目业务代码无需安装这些依赖。
npm install
npx playwright install chromium
python -m pip install -r requirements.txt

# 在业务代码工作区的独立终端启动隔离的录制服务。
$env:PORT='18796'
$env:HOST='127.0.0.1'
$env:PUBLIC_ORIGIN='http://127.0.0.1:18796'
$env:HUAWEI_AUTH_FILE="$env:TEMP\huaxiao-demo-video-auth.json"
node backend/agent/cloud-server.js

# 回到本录制目录执行。
python synthesize.py
node record.cjs --dry-run
node record.cjs
python produce.py
python verify.py
```

可以通过 `DEMO_MEDIA_DIR` 修改中间素材目录，通过 `DEMO_ORIGIN` 指向另一处相同产品页面。成片、字幕和脚本始终输出到当前用户桌面。录制程序在隔离认证库中创建随机密码的合成演示账号，实际输入和登录，凭据不进入本目录或版本提交。
