# 数据集工作区说明

## 负责人

D 数据与知识库工程师负责数据、清洗、切片、入库准备和质量；A 负责检索代码消费和验收，B 负责入库接口边界。

## 目录职责

| 目录 | 职责 |
| --- | --- |
| `raw/` | 原始证据、官网快照、固定清单和候选附件 |
| `cleaned/` | 可追溯的本地知识索引和清洗结果 |
| `test_sample/` | 仅用于测试的合成样例和示例输出 |

## 开始工作前

1. 阅读根目录 `团队协作与分工说明.md` 和 `文件归属与责任矩阵.md`。
2. 阅读 `../README.md` 和 `../agent_spec/README.md`。
3. 对齐 `../agent_spec/task_rule.md`、`constraint.md` 和 `acceptance.md`。

## 数据规则

- 每条关键事实保留来源库、具体条目、内容指纹、抓取时间和适用型号/SKU。
- 官网失败项保留失败状态，不补空价格或伪造成功。
- 原始资料、清洗索引和测试样例分开存放。
- 不加入真实客户隐私、凭据、日志、原始 ZIP 或模型权重。
- 图片候选不等于正式配图；未核验时保持 `model_verified=false`。
- `cleaned/image_review_registry.json` 只登记逐张核对型号、IMA 条目、原图 URL 和画面的草稿配图；即使 `model_verified=true`，人工终审或授权未完成时仍必须保持 `publication_ready=false`。
- 价格必须区分公开参考价、历史快照、起售价、补贴估算和可成交报价。

## 验证与交接

交付附数据计数、来源清单、清洗命令、测试结果、失败项和待核实项。A、B、C 或 E 发现问题时提交给 D 评估数据修正，A 复验检索链路，E 协助验收。
