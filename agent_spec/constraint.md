# 输出与合规约束

## 1. 事实与来源

- 每条产品事实必须可追溯到具体知识库条目或华为官方页面；保留来源名称、条目、URL、抓取时间、内容指纹和适用型号。
- 两个本地知识库内容冲突时，采用更新、更完整且能与官网交叉核对的口径，并记录「两库对比后采用 ___ 口径」。
- 无法核实的内容写「待核实」，不得用推测补齐价格、SKU、库存、政策或图片身份。
- 运行区不得直接携带原始 ZIP、完整官网原文、客户资料、日志、凭据或模型权重。

## 2. 价格与报价

- 价格记录必须区分公开参考价、历史快照价、搭配价、起售价和可成交报价。
- 缺少精确 SKU、配置、数量、地区、有效期和适用条件时，正式交易报价必须为空。
- 四级价格模型属于「基于行业惯例与赛题推断的可配置假设模型，待官方确认」；只能用于演示演算，不得冒充华为政策。
- 任何金额展示都要同时展示币种、数量、单位、假设条件、来源和「非正式报价」标记。
- 过期快照、未知库存、未登录状态或结算条件不明确时，不得输出确定性成交结论。

## 3. 客户画像与内容

- 明确区分客户原话输入、规则推断和待确认项；不得默认预算、身份或采购权限。
- 客户信息不足时先提出澄清问题，不能为了生成内容而编造行业、规模、决策链或痛点。
- 内容准备稿不得承诺成交、收益、最低价或未经证实的兼容性。
- 平台差异只能表述为内容结构建议；没有真实平台数据时，不得声称已经掌握平台推荐算法或真实转化效果。

## 4. 测试样例与效果

- 所有测试客户、对话和成交场景必须显著标注为合成样例，不能与真实客户记录混合。
- 合成测试通过只证明契约、边界和规则可运行，不证明真实咨询量、转化率或销售效果。
- 30 分钟演示是计划模板；未在真实场景执行前，`onsite_within_30_minutes_verified=false`。
- IMA 未接入时不得伪造 IMA 来源 ID；当前由本地知识库与华为官网替代，赛事合规差异须如实披露。

## 5. 图片

- 候选图附件不等同于正式产品图。每条记录至少要通过画面、型号、配色、SKU、版权和页面归属核验，才能标记为正式配图。
- 当前 112 条候选图均为未核验状态，正式配图计数为 0。
- 引用图片时必须同时保留附件路径、原条目、原始 URL（如有）和核验状态。

## 6. 禁止话术

- 禁止：「保证成交」「保证转化」「全网最低价」「官方已确认」「华为正式政策」等无证据表述。
- 禁止把历史价格、起售价、补贴估算或搭配价写成当前成交价。
- 禁止把规则准备稿写成大模型生成，把静态介绍写成在线推理，把未部署写成已上线。
- 禁止输出客户隐私、密钥、Cookie、令牌、内部链接或个人身份信息。

## 7. 发布边界

- 公开包只允许包含已审查、脱敏、可追溯的代码、文档、合成样例和许可明确的资产。
- 原始知识库、客户数据、运行日志、凭据和本机模型权重必须排除。
- 本地测试、Git 提交、部署和公网可访问是不同验收层级，不得互相替代。
