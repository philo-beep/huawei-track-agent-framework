# 华销智策销售顾问使用说明

## 1. 这个工具帮你做什么

华销智策把一次客户推进整理成四步：

1. **了解客户**：逐题记录客户原话、场景、需求、预算和采购阶段。
2. **找到合适的产品**：按客户需求查找候选型号，同时说明推荐理由、使用限制和待确认项。
3. **准备沟通内容**：生成公众号、小红书或朋友圈的内容准备稿。
4. **准备报价与下一步**：整理演示价格、客户演示方案和后续销售动作。

系统只负责整理和提示，不自动联系客户，也不替代销售判断或正式报价审批。

## 2. 使用前准备

- 只输入虚构或脱敏客户信息，不要填写真实客户隐私。
- 不使用系统密码、账号凭据或其他敏感信息作为客户描述。
- 产品型号请从页面提供的选项中选择。
- 预算、采购数量和采购权限不确定时，宁可留空，不要猜填。

## 3. 四步怎么用

### 第一步：了解客户

- 可直接输入已知客户背景，也可以从第一个问题开始。
- 每次只回答当前一个问题，尽量保留客户原话。
- 不确定的信息可以写“待确认”，系统不会自动把它当成已确认信息。
- 关键信息基本齐全后，页面会生成客户画像，并可一键带入产品匹配。

### 第二步：找到合适的产品

- 填写客户原话、使用场景、行业、产品类型、需求、偏好和排除项。
- 预算未知时可以留空。
- 结果里的“推荐顺序”只表示优先查看顺序，不等于匹配概率或成交概率。
- 先看三项内容：
  1. 为什么优先查看这个型号；
  2. 客户需求是否被资料支持；
  3. 还有哪些限制或信息需要向客户确认。

### 第三步：准备沟通内容

- 先在产品匹配结果中选择一个候选型号。
- 再选择公众号、小红书或朋友圈。
- 页面会分别展示：
  - 内容原稿；
  - 发布前检查结论；
  - 需要处理的问题；
  - 可直接使用的稳妥版本；
  - 待审图片和资料来源。
- 没有完成发布授权或人工终审的内容，不要直接对外发布。

### 第四步：准备报价与下一步

- “演示金额测算”只用于解释价格计算方式，不是华为官方政策，也不是客户成交价。
- “正式成交报价：待确认”表示当前还不能向客户报正式价格。
- 演示方案中的时间安排是准备建议，现场实际耗时仍要在演示时记录。
- 下一步动作会列出负责人、推进时机、完成标准和需要先确认的信息。

## 4. 页面状态怎么看

| 状态 | 销售含义 |
| --- | --- |
| 客户明确说明 | 客户原话或销售记录中有直接依据 |
| 推断，待核对 | 系统或销售做出的判断，需要向客户确认 |
| 待确认 | 当前没有足够依据，不应直接对外承诺 |
| 资料支持 | 已找到可核对的产品资料 |
| 仍需确认 | 现有资料不足，需要补问客户或补查资料 |
| 需要调整 | 内容存在可处理的问题，稳妥版本会移除相关内容 |
| 不通过 / 需先处理 | 当前版本不能直接使用，需要补齐资料或调整表达 |
| 销售准备稿已生成 | 可以用于内部准备和人工复核，不等于可发布或可成交 |

## 5. 三种下载怎么选

- **下载销售说明**：给销售、主管或客户方案沟通使用，内容更容易直接阅读。
- **下载数据备份**：给系统管理员、审计或存档使用，包含完整业务信息。
- **复制销售说明**：需要把内容粘贴到邮件、文档或聊天工具时使用。

## 6. 常见提示怎么处理

- **“智能分析暂不可用”**：稍后重试；持续不可用时联系管理员。
- **“产品资料需要更新或复核”**：先点击“重新检查”；仍不可用时联系资料维护人员。
- **“正式成交报价：待确认”**：不要向客户报金额，先补齐销售配置、数量、地区、有效期和有效价格依据。
- **“当前没有可直接使用的版本”**：按“需要处理的问题”逐项调整，再重新生成。
- **“浏览器未允许复制”**：使用下载按钮，或从页面中的完整销售记录手动复制。

## 7. 使用边界

- 不把公开历史价格当成当前成交价。
- 不把产品目录名称当成完整销售配置。
- 不把规格存在当成软件兼容已经验证。
- 不把系统生成的准备稿当成已发布内容或真实客户效果证明。
- 所有价格、兼容性、图片授权和客户动作，都要由相应负责人确认。
