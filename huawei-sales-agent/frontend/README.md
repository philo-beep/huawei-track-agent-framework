## 文件职责

- 预登录价值展示：见 `PRELOGIN_VALUE.md`。包含自建知识库与官网资料、画像驱动三平台草稿、明确标注的故事示意与可展开的省时假设；“0 幻觉”仅为设计目标，40 分钟仅为未实测的流程估算。

- 入口：`index.html`，无构建步骤。
- 样式：`static/css/styles.css`，当前为白底、深灰文字、华为红点缀的商务销售工作台；使用 CSS 花瓣标识，不引入远程字体或第三方脚本。
- 交互：`static/js/app.js`，负责产品匹配输入、规范产品信息、逐条件覆盖、理由/限制/逐字引文展示、核心证据折叠、四步输入、运行轮询和 JSON/Markdown 导出。
- 页面采用单步向导，同一时间只显示“客户画像 / 产品匹配 / 内容生成 / 报价与成交”中的一个步骤；顶部步骤条和底部上一步/下一步用于切换。未知信息保持空白或“待确认”，不能自动补造预算、身份、采购权限、价格或兼容性。
- 不直接连接模型或外部服务，只调用同源 `/api/*`。
- `build-demo-presets.cjs`：C 工作区的演示资产准备工具；只读调用已有本地 Agent 入口，禁止网络请求，将两组完整预置结果写入 `index.html` 的非执行 JSON 数据块。不会改变后端规则或接口。
- `demo-replay.test.cjs`：无第三方依赖的前端回放验证，使用 DOM 测试替身验证流程、零请求、权限、恢复和退出；图片加载及实际布局另做浏览器验收。

## 两个离线演示样例

2026-10-23 增加“自动填充：企业采购”“自动填充：自由职业创作者”两个按键，位于四步向导上方。

- 企业采购：30 人制造企业采购负责人，仓库与办公室移动办公；关注采购风险、配置确认和审批。最终展示固定 5 台的四级假设测算，非官方政策、非成交价。
- 自由职业创作者：个人用户在通勤、咖啡馆和家中改稿，关注文稿编辑、文件导出和沟通清单。预算未定，最终不启用 5 台报价。
- 两组均为合成客户，每组 6 轮问答。每轮先显示问题，1.6 秒后填入当前回答，再停留 4.6 秒读取该轮预置结果；逐步增长画像覆盖和原话证据。之后依次展示产品匹配、公众号、小红书、朋友圈和成交准备，完整自动播放约 1 分钟。
- 可随时暂停讲解，或关闭“自动播放预置流程”，用“填入本轮回答 / 确认本轮并保存”逐步推进。自动播放只读取预置，不冒充人工确认。手动确认才把该轮回答、结果与确认时间保存在本机。
- 确认记录按场景隔离，保存在 `localStorage` 的 `huawei.demo.confirmed.v1.<场景>`；基础键保存最后一次确认记录。刷新后可点“继续已确认进度”恢复连续确认的问答；预置指纹变化、损坏或旧版本记录会忽略。浏览器不允许保存时提示导出演示包，回放仍可继续。仅保存固定合成问答，不接收普通客户输入。
- “导出预置演示包”下载两组全部问答、画像结果、产品匹配、六套图文、成交准备和本机确认记录。各结果下载也使用本地 Blob，产品原图包为包含原文件 Base64、文件名、来源和授权状态的 JSON。

页面、脚本和预置已加载并完成本地登录后，演示不再依赖服务端任务或外部网络。正常启动仍需 Python/Node 本地服务；首次加载和登录仍走现有接口。演示期间不调用 `/api/profile-steps`、`/api/product-matches`、`/api/content-drafts`、`/api/runs`、`/api/source-status`，不占生成限额；统一 API 入口也拒绝演示模式发出请求。演示退出后恢复正常模式，正常模式仍执行原有实时资料时效和发布门禁。

图片采用精确型号审稿清单中的产品原始 PNG/JPEG，按 SHA-256 去重后保存在预置 `product_images` 中，三个平台分别显示 4 / 3 / 1 张。图片字节保持原样，保留来源和公开发布授权待确认状态，不以场景 SVG 替代产品原图。原稿六项发布核验为录制时审稿快照，不能替代当前审核。

## 修改边界

- 只修改 `frontend/` 和分配给 C 的 `assets/` 中前端可见内容。
- 不复制后端规则，不猜测缺失客户信息，不隐藏限制和来源。
- 不引入未审查的第三方脚本、远程字体或追踪代码。
- 页面能力必须与实际 API 和当前规则模式一致。
- 当前使用原生 HTML/CSS/JavaScript；Vue、Tailwind 或流式渲染如后续引入，必须单独说明，不能写成已经完成。

## 逐步客户画像

- 首问由程序给出；用户填写已知背景后，调用 `/api/profile-steps` 由云端模型决定更合适的下一问。
- 每轮只渲染一个问题，快捷选项只填入回答框，不替客户提交；提交后轮询 `/api/runs/{id}`。
- 页面展示追问轮次、10 个维度覆盖、核心维度 6 项阈值和当前缺口；达到阈值或 8 轮上限后显示画像卡片。
- 画像字段必须保留原话依据；预算未定时不写入金额。完成后可一键带入产品匹配，未知字段保持空白。

## 产品匹配后的图文生成与强制核验

- 每个匹配候选提供内容生成按钮；页面选择公众号、小红书或朋友圈后调用 `/api/content-drafts`，由后端重新核验，不直接信任页面状态。
- 结果区先展示发布门禁结论、六项逐项核验和风险项清单，再展示原稿与审稿图片。
- 内容工具栏提供“快速查看全文”，标题、正文、标签预览块各自提供“查看全文”；原生对话框内可完整滚动阅读，并支持单段复制或一次复制全部文案。
- 六项结果为“通过/不通过/降级”：不通过显示为阻塞；可剥离的图片授权或正文价格问题作为降级项，安全版本中不得再出现对应图片、标记或段落。
- 可发布安全版本单独展示，附带降级说明；原始稿、图片、来源清单、插入位置和完整 Markdown 仅用于审稿及下载。
- 图片通过同源 `/api/content-images/<sha256>` 展示；草稿固定提示公开发布授权和人工终审未完成。
## 预登录、登录与权限展示

- 首页先显示品牌化预登录页，点击“进入销售工作台”后进入登录/注册界面；未登录时业务工作台默认隐藏且不会请求示例数据。
- 登录使用 HttpOnly 同源会话 Cookie，不把会话令牌写入 localStorage；`auth.js` 只保存当前用户与 CSRF 令牌的服务端返回值。
- 首个注册账号自动成为管理员，后续账号默认为成员。管理员可从页头“用户与权限”打开抽屉，修改角色或停用账号。
- 角色包括管理员、成员、只读。只读账号可以登录并查看界面，但运行按钮禁用，服务端仍会二次返回 403，不能只靠前端隐藏。
- 配置权限调整使用会话级 CSRF 令牌；接口返回 401 时会回到登录界面，返回 403 时保留当前页面并显示权限原因。
- 动效包括预登录场景漂移、卡片浮动、登录入场和面板切换；支持“暂停动效”和 `prefers-reduced-motion`。
- 移动端保留退出登录入口；窄屏下隐藏用户名文字但保留头像与操作按钮。
