# 销售文案盲测包

## 文件

- blind_review_pack.md：发给销售评审的 A/B 盲测包，A/B 顺序已打乱。
- blind_review_key.json：A/B 映射与代理评分，只由组织者保存。
- blind_review_form.csv：每位评审复制一份填分。
- blind_review_report.md：代理预检汇总与待填写的真人结果。
- samples/：公众号、小红书、朋友圈三份文字可发示例稿。
- samples/media-plan.json：精确型号配图顺序、来源、授权状态和本地路径。

## 真人测试流程

1. 至少邀请 5 名实际销售，覆盖企业采购、教育和个人/小微客户。
2. 只发 blind_review_pack.md 和一份 blind_review_form.csv，不发密钥。
3. 每份稿独立评分：自然度 1—5；只需小幅修改即可发布 1—5；愿意发布 1—5。
4. 汇总时：“可编辑”定义为可编辑分≥4；“愿意发布”定义为愿意发布分≥4。
5. 门槛建议：自然度≥4.0；可编辑率≥80%；愿意发布率≥70%。
6. 若真人结果与代理结果不一致，以真人结果为准，并记录新稿仍存在的具体编辑点。

## 当前代理预检

- 样本：3 类人群 × 3 个平台 = 9 组 A/B。
- 旧模板稿：自然度 2.20 / 可编辑率 33.3% / 愿意发布率 0%。
- 受控创意稿：自然度 4.71 / 可编辑率 100% / 愿意发布率 100%。
- 解释边界：这是规则化代理评分，只说明明显模板痕迹和结构问题已被消除，不代表真人销售已验收。

## 生成命令

~~~powershell
node tests/blind_review.js
~~~

脚本只读取公开样例和已清洗数据，不调用外部模型，不提交真实客户数据。
