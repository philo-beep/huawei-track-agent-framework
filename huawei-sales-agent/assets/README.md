# 资产说明

C 前端开发为主负责人，E 协助核对演示材料、公开描述和限制；其他角色不得直接覆盖已发布资产。

## 开始工作前

依次阅读项目根目录 `README.md`、`团队协作与分工说明.md`、`文件归属与责任矩阵.md`，以及运行区 `../README.md`。

本目录用于答辩截图、logo 和演示素材，当前不存放原始知识库图片，也不存放模型权重。

## 小麦吉祥物

- `xiaomai-full.svg`：原创侧面全身矢量稿，展示小麦抬爪招呼、卷尾巴和华为红围巾的陪伴姿态；页面实际使用的 SVG 符号与该稿保持一致。
- `xiaomai-full.png`：同一稿的透明背景预览图，供评审、汇报和后续视觉延展使用。
- 来源：本项目内绘制，无外部图片、远程字体或第三方素材依赖；授权状态：项目自有，可用于本项目页面和汇报材料。
- 应用位置：预登录欢迎页主视觉、登录介绍陪伴气泡、已登录工作台左侧流程栏和客户画像提示卡。吉祥物只承担引导和陪伴表达，不承载产品事实、价格或权限判断。

候选产品图位于并行数据区 `../huawei-sales-agent-data/datasets/raw/assets/`，均标记 `model_verified=false`，需要人工核对画面、SKU、配色和版权后才能作为正式配图。正式图片计数为 0。

## 工作规则

- 新增资产必须记录来源、授权、适用页面和是否允许公开。
- 未完成版权、画面和型号核验的图片不得标记为正式产品图。
- 不把数据区候选附件直接复制为本目录正式资产。
- 删除或替换资产前确认页面引用和公开声明。

## 交接

新增或替换资产需说明来源、授权、适用页面、文件指纹和核验状态；未授权或未核验资产只能登记为候选，不能标记为正式公开资产。
