# 销售文案去技术化修改清单

更新日期：2026-10-22
修改范围：主工作区销售工作台、生成结果、导出文档与销售使用说明。
原则：只修改展示层和文案，不改变选品、画像、价格计算、发布检查等业务逻辑。

## 五、保留的技术内容及原因

以下内容没有删除，但不会作为销售主视图：

- JSON 下载：保留完整字段、编号、校验信息和接口数据，供技术、审计和系统集成使用。
- 开发者 README、接口契约、数据字典、测试脚本：属于研发和验收资料，不是销售操作界面。
- 图片文件校验信息、资料更新时间、公开页面链接：用于发布责任人和资料维护人员追溯，不在销售主视图展开。
- 产品规格中的“接口”“指纹电源键”“OLED”等：属于产品事实，不是开发术语，不能改写。
- 四级价格测算的内部金额单位：只保留在 JSON 数据中；销售说明统一显示元。
