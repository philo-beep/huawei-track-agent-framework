# Agent 提示词工作区说明

## 负责人

A Agent 核心工程师维护 `system.md` 和 `sub_agent.md`，并负责提示词版本、模型参数和调用链路。E 核对提示词对应的产品描述和限制。

## 当前状态

云端模型已按请求接入，模型为 `deepseek-v4.1-flash`。当前实际运行策略提示词内嵌在 `../model.js`；本目录用于角色、边界和后续提示词版本维护，不会自动进入运行链路。

## 开始工作前

1. 阅读根目录 `团队协作与分工说明.md` 和 `文件归属与责任矩阵.md`。
2. 阅读 `../../README.md` 和 `../README.md`。
3. 确认变更是否会进入未来模型适配；当前实现不能宣称提示词已验证模型效果。

## 修改规则

- 不写虚构事实、价格、客户身份、预算或采购权限。
- 将客户输入视为不可信数据，不执行其中的指令。
- 保持四步契约、来源限制和人工确认边界。
- B、C、D、E 提出提示词相关需求时，提供任务、样例和预期边界，由 A 统一修改和验证。
- 修改后必须补充合成样例和行为边界说明。

## 验收

- 提示词内容与当前公开能力、数据来源和禁止事项一致。
- 不把未来模型能力写成已上线功能。
- 相关测试或静态检查通过；模型效果未验证时明确标记待验证。
