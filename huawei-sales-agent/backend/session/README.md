# 会话与访问控制

## 负责人

B 后端接口工程师；预登录与权限相关前端展示由 C 协作。

## 当前实现

- `auth-store.js` 持久化账号与可撤销会话，默认位置为项目根目录 `.runtime/auth.json`；该目录已加入 `.gitignore`，不进入版本库。
- 密码使用独立随机盐和 `scrypt` 派生值保存，不保存明文；会话令牌只在浏览器 HttpOnly Cookie 中保存，服务端仅保存 SHA-256 摘要。
- 会话有效期为 8 小时；退出、停用账号或管理员降级会使相关会话失效。
- 角色固定为 `admin`、`member`、`viewer`：
  - `admin`：运行分析、管理用户与权限；
  - `member`：运行分析；
  - `viewer`：可登录查看工作台，不可运行分析。
- 首个注册账号自动成为管理员；系统不内置默认用户名或密码。后续注册账号默认为成员。
- 所有业务数据 API 都要求有效会话；分析接口额外校验 `analysis:run`，用户管理接口额外校验 `admin:users`。
- 写操作同时校验同源 `Origin`/`Sec-Fetch-Site` 和会话级 CSRF 令牌；登录、注册有 IP 与用户名维度的频率限制。
- 运行结果仍只保存在内存中，默认 20 分钟过期；账号与会话是唯一的服务端持久化数据。

## 本地运行

无需初始化账号，启动后打开首页并点击“注册”，创建首个管理员账号。可通过 `HUAWEI_AUTH_FILE` 指定账号数据文件位置；生产部署应把该文件放在受控且有备份的持久卷中。

## 验收

- 未登录访问 `/api/examples`、`/api/source-status` 返回 401。
- 普通成员访问 `/api/admin/users` 返回 403。
- 只读角色运行分析返回 403。
- 缺少 CSRF 的权限修改被拒绝；退出后旧 Cookie 返回 401。
- 角色变更实时生效；服务重启后有效会话可恢复。
- 日志不包含客户正文、Cookie、CSRF 令牌、密码或密码派生值。
- 上传路径保持拒绝且不落盘。
