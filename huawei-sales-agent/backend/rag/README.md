# RAG 工作区说明

## 负责人

A Agent 核心工程师负责 RAG 检索代码；D 数据与知识库工程师提供清洗数据、文本切片、向量索引和检索质量证据。

## 职责

- `embed.py`：本地哈希向量或嵌入适配。
- `vector_store.py`：本地向量检索、排序和来源字段保留。
- 从 `../../../huawei-sales-agent-data/datasets/cleaned/local_kb_index.json` 读取已审查索引。

## 开始工作前

1. 阅读根目录 `团队协作与分工说明.md` 和 `文件归属与责任矩阵.md`。
2. 阅读 `../README.md`、本文件和数据区 `../../../huawei-sales-agent-data/datasets/README.md`。
3. 确认当前任务使用允许的数据版本，不调用未授权外部服务。

## 修改边界

- 不复制或改写原始知识库资料；数据采集、清洗、切片和索引质量问题交 D。
- 不引入权重、联网下载或未审查模型依赖。
- 检索结果必须保留条目、来源库、指纹和适用限制。
- 不把合成检索结果描述为真实客户效果。

## 验证

- 覆盖空索引、重复命中、无结果和来源保留。
- 运行 `python -B -m unittest discover -s tests -v`。
- 交付附索引版本、查询样例、命中数量和来源完整性结果。
