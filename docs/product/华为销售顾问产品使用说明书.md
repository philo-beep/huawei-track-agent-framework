# 华销智策 —— 针对华为的销售智能体：销售顾问产品使用说明书

版本：2026年10月18日。正式名称：华销智策 —— 针对华为的销售智能体。供需要整理客户需求、准备华为电脑介绍和方案的销售顾问使用。需求来自用户与赛题，没有进行市场调研。

## 一、它解决什么问题

| 销售痛点 | 现在能做什么 | 解决程度 |
| --- | --- | --- |
| 客户描述零散，难以有据地写不同渠道内容并带来咨询 | 整理十一维画像，按公众号、小红书、朋友圈准备文字，附来源、限制和咨询建议 | **部分解决。** 正式图片为0；自然软文质量与真实咨询增量未验证 |
| 报价组合复杂，希望半小时内形成方案 | 演示四级价格计算，列物料、人员、0—30分钟操作、验收与失败替代 | **仅完成假设演算和方案准备。** 缺真实授权价格政策及完整商品现价，现场半小时未验证 |

当前版本已完成核心功能完整实现（四步闭环可运行、可演示），前端UI属于后续优化项，将在功能稳定后迭代美化。“完整”仅指准备稿、假设演算和人工行动建议，不包括真实交易报价、完整营销图文及转化效果。

**两种环境分开使用：**本机增强版实际调用本地千问；公开云版为规则准备稿，未接云端大模型，不带任德耀私有知识库，只使用公开官网资料和合成案例。公网部署结果、版本与外网验收以根目录 `SUBMISSION.md` 为准，历史框架页不能代替本版业务演示。入口见根README。

## 二、按四步操作

### 打开和填入案例

本机双击 `启动网页助手.cmd`，浏览器打开 `http://127.0.0.1:8767/`，保持服务运行。公开版从README演示入口进入，输入会提交至公开服务，请只用脱敏或合成信息，不填姓名、电话、公司机密或密钥。

按 `Alt+1/2/3` 或案例按钮只填入合成样例，不自动运行。确认完整型号和代际、客户描述、具体场景及公众号/小红书/朋友圈；按 `Ctrl+Enter` 或“运行四步”才开始。快捷键若被系统占用，直接点按钮。实际浏览器按键、画面和点击下载尚未实测，模拟网页事件不能替代真浏览器验收。

换客户先点“新客户”，重新确认身份、数量、预算与采购权限，不能继承样例事实。云版价格演示固定5台，5台是合成数量，不是客户需求；本机可查看假设配置，不匹配时先看阻塞原因。

### 第一步：读懂客户

先看画像和追问。系统将客户原话分成十一维：

| 维度 | 顾问怎样使用 |
| --- | --- |
| 身份 | 区分使用者、联系人，不猜最终审批权 |
| 客情 | 新客、老客或未知；老客不等于续约 |
| 行业 | 只采用明确行业，不由工作任务猜测 |
| 规模 | 员工、门店、设备分别记录，采购量不等于员工数 |
| 需求 | 明确本次任务、优先级及缺少的软件版本 |
| 预算 | 区分单台/总额、币种和数量，未知留空 |
| 决策链 | 分清谁使用、比较、审批，不由岗位猜权限 |
| 偏好 | 按客户已表达的关注点调整介绍顺序 |
| 痛点 | 引用真实障碍，有据推断仍待确认 |
| 购买阶段 | 区分了解、比较、审批，不直接认定成交意向 |
| 可触达渠道 | 确认实际渠道及联系许可，发布平台不等于授权 |

优势是每项能回查输入，明确、推断、待确认分开，同一客户换平台不会自动换身份或预算。它不是客户打分器，不保证真实客户识别准确率。矛盾先追问，不以填满未知冒充完整画像。

### 第二步：写出内容

查看标题、导语、正文、咨询引导和来源。公众号分段说明，小红书短清单，朋友圈突出一个重点。当前为受控核对准备稿，需顾问检查场景、产品限制及措辞，不代表自然可发布软文已通过。

**IMA已由本地知识库 + 华为官网替代，资料来源标注已保留。** 本机画像、内容和通用知识以任德耀库为主要来源；参数、配置和价格优先同代际官网/商城。云版不带私库。旧IMA输入及已有凭证均不会触发请求，不需办理IMA授权。

关键资料保留具体条目/页面、原文和内容指纹；官网另留抓取时间、型号及配置限制。型号代际不混用，系列选项不能任意拼成在售商品。本次官网7来源中5成功、2商品链接重定向失败，两代共10个系列参数，**全部公开价格仍待核实**。正式图片为0，候选图保留来源但未经画面、配置和使用条件审核，不能凑图。

### 第三步：给出方案

未勾选价格演示时金额保持空，列出待确认条件，仍可看画像、内容和准备计划。勾选后演示“客户类型→采购数量→产品配置→区域”四级计算。

**此为基于行业惯例与赛题推断的合理假设，待官方确认。** 分类、基价、系数、优惠、日期、地区和资格均人为配置，未取得华为或行业验证。示例6000元→9.8折后5880元→每台减100元后5780元→配置保持→区域折扣受50元单级优惠封顶后5730元；5台28650元。不是华为现价、客户预算或授权优惠。

真实交易价始终为空；即使取得官网零售价，也不自动取得门店四级政策、库存或优惠资格。顾问须核对完整商品配置、地区、税费、有效期和授权政策。

0—30分钟表列设备软件、资料、人员、操作、输出、验收和失败替代，只是建议。真实设备上应记录打开、编辑、保存、导出与客户验收；程序生成文件17.092秒不证明现场半小时完成。

### 第四步：推进成交与留存

按动作、责任人、触发条件、依赖安排人工跟进。例如先确认软件版本，再整理兼容性材料。应用不自动联系客户、预约、发消息或报告成交。

核对限制后下载JSON或Markdown，前者便于系统复核、后者便于阅读。公开版使用临时会话，过期或重启结果可能失效，及时保存。关闭页面不等于取消后台任务，运行中勿重复提交。显示“待确认/阻塞”先看原因；进度完成不等于业务成功，无正文不能当成功稿。
