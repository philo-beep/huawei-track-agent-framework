## 价格结论

**当前全部`price=null`，币种与具体交易金额未核实，不得声称“官网现价已核准”。** 商品页未真正取得，不能提供精确配置、SKU、库存、可购买状态、税费、优惠资格和有效期完整证据。官网鸿蒙购买链接含`prdId=10086097339191`和`sbomCode=2801010196907`，这只是页面链接标识，不是已核准SKU配置和价格。2024产品页的6799元出现在HTML注释块中，静态可见正文未展示，已排除，不是现价证据；商城首页的搜索摘要价格也未纳入。未将划线价、国补、券后价或“起”价升格为无条件单价。

正式报价继续阻塞金额并提示核实官网商品配置/价格，不使用本地历史快照填空。既有四级假设政策演示与真实报价保持隔离。即使日后取得准确官网零售价，也不自动取得四级门店政策授权。

## 机器接口与溯源

`data/official/manifest.json`含`schema_version=1`、`ima_required=false`、`ima_requests=0`和`entries`。每条有`id/source_type/url/final_url/fetched_at/fetch_status/http_status/title/product/product_family/model_identity_verified/sku/configuration/text/fields/price/images/limitations/attempts`；失败条目路径和价格为null，不冒充成功。`raw_path/raw_sha256`指向真实响应字节，`text_path/text_sha256`为HTMLParser去除script/style/comment后的UTF8 LF正文。`source_pointer.start/end`是正文Unicode字符偏移；`source_pointer.path/sha256`绑定实际正文文件；`excerpt`必须逐字等于该范围。

规格`fields.scope=model`，`sku=null`，说明只是产品系列参数；字段摘录保留紧邻版本限定。输出时应展示实际型号、来源URL、抓取时点和限定，不能只转述value。元数据product由官方链接页面确认代际；`model_identity_verified`不代表用户SKU匹配。正文完整保留所有原网页脚注，消费者不能跨代复制功能与参数。

本轮`images=[]`，未引入新图片，因此不虚报“正式配图已完成”。既有本地图仍为待审核候选，输出时保留原库条目和图片URL；未完成画面、配色、SKU、使用权限核验前，不作为已核准商品图。网页公开可读不等于取得独立商业图片授权。网页快照限本机开发审计，不直接进入公开发布包。

## 运行与失败处理

```powershell
python data/fetch_official.py
python data/fetch_official.py --targets data/official/harmony-targets.json --merge
python data/fetch_official.py --normalize-text
```

默认目标为上述7页，输出固定为`data/official/manifest.json`。`--targets`接受受限官网URL列表，`--merge`按id更新指定项，其余条目保留原抓取时间；不加merge则重新建立当前清单。`--normalize-text`仅离线规范派生正文LF并核对原始网页指纹，不联网、不刷新采集时间。抓取失败会写入attempts、返回结果清单并保留blocked价格，不因IMA配额或缺少凭证终止流程。CLI成功退出只表示清单已生成，不表示所有网页或价格已获取，调用方必须逐项检查`fetch_status`。

首次D接入发现Windows正文写入CRLF而原声明按LF哈希，已修为write_bytes UTF8并对既有正文离线规范；该修复不改网页原始字节或抓取时点。旧C001未更改。实际独立验收见QA评审，不能以数据Agent自测代替业务报价验收。

QA退回后的最小修复：初始和重定向来源URL均拒绝username/password，仍只允许HTTPS官方精确host及默认/443端口。型号身份核验绑定脚本受支持的目标ID、原始URL、目标型号、最终官方路径、页面标题及代际原文特征；未知目标、跨代跳转或特征不一致均保持`model_identity_verified=false`且不抽取fields，新增限制说明。2024规格若被重定向到鸿蒙规格，即使两者标题同含MateBook 14也不认证为2024。该修复仅修改采集判定，当前7条清单与原始网页字节未改变，无重新联网。
