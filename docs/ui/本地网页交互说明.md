# 本地网页交互 v1

本轮使用原生 HTML / CSS / JavaScript，静态目录 `frontend/growth`，无构建和第三方前端依赖。由 D 的 Node 本地服务提供同源页面与 API。唯一 API 依据是 `docs/api/local-web-v1.md`，营销和定价沿用既有 B 契约。

## 操作指引与快捷键

1. 从本地服务打开页面，在页面阅读四步指引。
2. 按 Alt+1 / Alt+2 / Alt+3 或按钮只填充合成示例，不自动调用模型。
3. 核对产品完整型号、客户原话、受众、场景、平台、已确认数量与总预算。点击“新客户”清空旧客户字段；修改原话或受众会清空旧客户结构、数量预算并关闭假设报价，防止继承旧事实。
4. Ctrl+Enter 或运行按钮发起真实本机流程。加载时禁用重复提交，每秒轮询。暂停查询只停浏览器轮询，不声称取消后台任务。
5. 按四区核对画像证据、内容准备稿、合成逐级算式和0–30分钟建议方案、人工推进动作。下载或复制完整 Markdown / JSON，保留来源。

## 客户与价格边界

可选客户 JSON 明文显示，不能隐藏继承客户事实；数量预算由已确认表单字段覆盖。示例全为合成。更改产品不会偷偷同步政策产品，更改采购数量会清空旧合成资格键，因此不匹配或未确认资格应在结果中阻塞。合成政策原始 JSON 可查看和替换；不得作为官方政策。未选合成演算时不发送 pricing_input，由既有后端返回价格待核实/阻塞结果。

网页明确保留“IMA 已由本地知识库 + 华为官网替代，来源标注保留”。官网参考和合成价格分区展示，真实报价始终以业务字段为准。结果完成与业务成功分开显示：completed仍可能需要澄清或阻塞。正式配图为0时如实显示缺口，未加载未经核实的图片。

## 安全与异常

所有客户、模型、来源、Markdown内容只用 textContent / DOM节点渲染；外部来源仅http(s)可点击，开启noopener noreferrer。无外部脚本、字体、图片或遥测；网页只访问同源本机API。CSRF token从GET examples获取，仅发同源POST。HTML输入限制用于体验，真正字段/权限/大小校验由后端负责。

网络失败保留运行ID，提示继续查询，不冒充取消或允许重复启动。POST失败提示安全错误并恢复输入；复制被浏览器拒绝时提供下载/手动复制替代。导出仅表示请求下载，需浏览器确认实际文件。

本轮不做美化。真实模型时长、当前官网核验状态和端到端浏览器交互证据由主控/独立QA实际运行后记录，不以本说明代替实测。
