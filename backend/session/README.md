# 会话与隐私

## 负责人

B 后端接口工程师。

## 开始工作前

先阅读项目根目录 `团队协作与分工说明.md`、`文件归属与责任矩阵.md` 和 `backend/README.md`。Agent 上下文需求与 A 确认，前端展示与 C 确认。

- 会话由 `backend/agent/cloud-server.js` 在内存中管理，默认 20 分钟过期。
- 每会话最多 3 次运行、间隔至少 2 秒；全局 10 分钟窗口最多 60 次，避免演示被滥用。
- 不把客户原话、Cookie、CSRF 令牌或运行结果写入磁盘；日志只记录 HTTP 方法、路径和脱敏错误。
- 不接收文件上传，不保存真实客户资料、凭据、模型权重或原始知识库。
- 需要跨会话保留时，应由用户在获得授权后另行导出；当前版本不提供服务端持久化。

## 验收

- 会话过期、次数限制和并发限制可复现。
- 日志不包含客户正文、Cookie、CSRF 令牌或凭据。
- 上传路径保持拒绝且不落盘。
- 变更后运行完整离线测试和 HTTP 冒烟。

## 交接

交付需说明会话状态变化、过期和限流参数、隐私影响、持久化边界、测试结果及需要 A 联调或 E 验收的内容。
