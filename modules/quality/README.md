# M5 质检与交付功能

负责人M5；代码区`modules/quality/`，合成交付报告`outputs/M5/`；分支`feat/quality-delivery`。

输入为客户画像、事实图片包、写作任务书和稿件；输出为逐项核验、可定位问题及责任模块、pass/needs_revision/blocked判断，以及可导出的四部分结果。核验覆盖事实、型号、限制、图片、平台、画像贴合、价格误导和凭据泄露。

只返回核验结论和定向修复要求，不擅自改上游画像、事实或稿件。不因语句自然放行错误事实，也不因出现数字就一律拒绝有来源参数。最多返修轮数由集成层控制，超限标明待人工复核。

本模块是产品功能开发，独立QA仍由原QA角色担任；作者不能给自己验收。使用`src/prompts/tests/fixtures/docs`及`async run(input, context)`，允许用明确合成的错误稿独立开发。当前未实现新核验器或导出器。
