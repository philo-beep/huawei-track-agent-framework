# M4 自然写作与编辑

负责人M4；代码区`modules/writing/`，合成交付报告`outputs/M4/`；分支`feat/natural-writing`。

输入为M3写作任务书、M2核验事实及可用图片；输出为完整标题、导语、正文、行动引导、平台标签与配图安排，另交句子对应的fact_id/image_id及修改记录。不得让程序固定模板覆盖模型已经生成并通过核验的自然正文。

自然表达不等于虚构亲测、客户评价、故事、优惠或能力。不以所谓AI检测率作为验收承诺；事实改写保留范围与限制，文风编辑不增加无来源结论。

入口`async run(input, context)`；各自使用`src/prompts/tests/fixtures/docs`。模型通过context注入，缺资源明确降级或阻塞，不能把规则稿标为模型稿。验收包含换人群、换平台、自然表达人工评审、事实保持和临时修改。当前尚无新写作实现。
