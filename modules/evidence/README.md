# M2 资料与图片

负责人M2；代码区`modules/evidence/`，合成交付报告`outputs/M2/`；分支`feat/evidence-retrieval`。

输入为产品完整型号、资料查询需求及可选M1画像；输出为事实包、图片包、来源原文、适用条件、抓取及到期时刻、许可状态和冲突。可按原始请求先开发检索，再支持画像细化查询。

本模块不写软文、不选择营销角度、不补造价格或许可。IMA继续停用，官网与本地来源保留差异说明；私库只经注入的只读资料接口读取，不复制进Git。无法核实的图片不标为可发布。

各自使用`src/prompts/tests/fixtures/docs`；入口约定`async run(input, context)`。验收覆盖相近型号、过期资料、空结果、来源冲突、无价格和无图片许可。当前仅搭建目录，未新增检索功能。
