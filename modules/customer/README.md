# M1 客户理解

负责人M1；唯一可修改代码区`modules/customer/`，合成交付报告可放`outputs/M1/`。分支`feat/customer-understanding`。

输入为客户原话、产品、人群、场景、平台及可选已确认字段；输出为十一维画像、原话依据、明确/推断/待确认标记、冲突和追问。不能把场景推断成客户预算、身份或采购权限。

本模块负责画像和追问，不负责选择产品卖点、写稿、报价或发起客户联系。开发者在自己的`src/`实现`async run(input, context)`，单独编写`tests/`；`prompts/`放提示词，`fixtures/`放合成输入输出，`docs/`放设计与交付说明。

验收至少覆盖信息极少、未知预算、矛盾输入、多人决策、换客户后信息不残留。依赖接口草案见`../../协作工作区/共享规范/接口草案/交接约定.md`。当前仅搭建目录，业务实现与测试待负责人交付。
