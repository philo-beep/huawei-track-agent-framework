# M3 内容策略

负责人M3；代码区`modules/strategy/`，合成交付报告`outputs/M3/`；分支`feat/content-strategy`。

输入为M1画像、M2事实包与发布要求；输出为写作任务书：读者、实际问题、购买阶段、内容目标、文章切入点、按相关性排序的fact_id、结构、语气、图片位置和一个主要行动目标。

不能发明新产品事实或直接改上游画像。更换人群后切入点与卖点顺序须有依据地变化；更换平台后结构、语气、图片方案与行动引导应变化，不能只换篇幅。

入口`async run(input, context)`；源码、提示词、自测、合成样例及内部文档分别位于`src/prompts/tests/fixtures/docs`。可先使用已标注的合成上游结果独立开发，不能把合成测试当端到端实测。当前未实现新策略引擎。
